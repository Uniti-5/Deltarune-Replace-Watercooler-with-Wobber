# Deltarune-Replace-Watercooler-with-Wobber

This mod changes the sprite from Watercooler to Home Paige’s Wobber (visible in the trailer of Home Paige)

It was my very first mod, it’s thanks to him that I started to get into UT/DR modding and video games in general.

This mod is not crazy, it only changes 3 sprites and is only available for Chapter 3, it’s just a simple archive of my first mod

By the way, go see the demo of Home Paige to support the developers of the game where the basic character comes from!
